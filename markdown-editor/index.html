Everything a serious writing tool needs. Nothing it does not.

Built with native Android components and Material Design 3, so it stays smooth even with thousands of notes.

Real time split preview

Raw Markdown on one side, formatted output on the other. Rendering is powered by Markwon for native performance, and the layout adapts to portrait and landscape.

Write and read side by side with zero latency. Quick insert tools add bold, italic, headings, code blocks, tables and links in one tap.

Biometric app lock

Protect notes with fingerprint, face unlock or device PIN. Authentication is requested on open and when returning from the background.

Auto save and undo

A customizable auto save timer and a robust undo and redo manager mean you never lose progress.

Archive and trash

Archive what you want to keep, trash what you do not. Trash can purge old notes automatically after a time you choose.

Complete offline backups

Export notes and settings as a single ZIP file and import it on any device. Scheduled background backups run through WorkManager, and you decide where the file goes: local storage, an SD card or your own cloud.

Light, dark and system

A clean Material 3 interface with list and grid views, and a styled WebView reader that follows your theme.

Images and links

Load remote images with Glide. Hyperlinks are detected and underlined automatically.

Three ways to read your writing.

Move between drafting, reading and sharing without leaving the app or touching a server.

  1. Draft in split view

    Type Markdown and watch it render instantly beside your text.

  2. Read in full screen

    A WebView with a custom Marked.js engine gives styled code blocks, tables and images.

  3. Export and share

    Send notes as PDF, as a Markdown file, or as plain text.

Your notes never leave your device.

Notes live in a local Room database. There are no trackers, no analytics, no ads, no subscription and no account to create.
